# Nodify.Me documentation

The published help articles for [Nodify.Me](https://nodifyme.app): how to add a server, what the agent does, how to deploy apps, set up a domain and HTTPS, and what each alert means.

**Read them at [nodifyme.app/docs](https://nodifyme.app/docs).** That is the place to read, search and follow links between articles.

This repository holds only the published files that the site reads. It is updated when an article changes, so it is not a place to send edits or questions. For help with your own account or server, sign in to Nodify.Me and use **Get help**.

The Nodify.Me agent, which you install on your own server, has its own public repository: [gsmarketing/nodifymeapp](https://github.com/gsmarketing/nodifymeapp).
